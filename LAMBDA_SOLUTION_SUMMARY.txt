BEFORE (ECS):
────────────

User → ALB (HTTPS) → ECS Fargate Container (HTTP:8080)
                     ├── Running 24/7
                     ├── Docker image from ECR
                     ├── Flask web server
                     └── Gunicorn workers
                     ↓
                  SageMaker API

AFTER (Lambda):
──────────────

User → ALB (HTTPS) → Lambda Function
                     ├── Pay per invocation
                     ├── 128MB memory
                     ├── 30s timeout
                     ├── Python 3.11
                     └── Auto-scaling
                     ↓
                  SageMaker API

Key Difference:
• ECS runs continuously (24/7) = always paying
• Lambda runs on-demand (per request) = pay only when used

╔═══════════════════════════════════════════════════════════════════════════════╗
║                         MONITORING & TROUBLESHOOTING                          ║
╚═══════════════════════════════════════════════════════════════════════════════╝

View Lambda Logs:
────────────────

aws logs tail /aws/lambda/sleetgale-portal --follow

Test Lambda Function:
────────────────────

aws lambda invoke \
  --function-name sleetgale-portal \
  --payload '{"path":"/health","httpMethod":"GET"}' \
  response.json

cat response.json

Check Lambda Status:
───────────────────

aws lambda get-function --function-name sleetgale-portal

Update Lambda Code:
──────────────────

cd portal
zip lambda_handler.zip lambda_handler.py
aws lambda update-function-code \
  --function-name sleetgale-portal \
  --zip-file fileb://lambda_handler.zip

Or just run: ./deploy-portal.sh
