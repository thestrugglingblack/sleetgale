Quick Start:
────────────

Manual Deployment:
──────────────────

# Get ECR repository URL
ECR_REPO=$(terraform output -raw portal_ecr_repository)

# Login to ECR
aws ecr get-login-password --region us-east-1 | \
  docker login --username AWS --password-stdin $(echo $ECR_REPO | cut -d'/' -f1)

# Build and push
cd portal
docker build -t sagemaker-portal .
docker tag sagemaker-portal:latest $ECR_REPO:latest
docker push $ECR_REPO:latest

# Update service
CLUSTER=$(terraform output -raw portal_cluster_name)
SERVICE=$(terraform output -raw portal_service_name)
aws ecs update-service \
  --cluster $CLUSTER \
  --service $SERVICE \
  --force-new-deployment

Monitoring:
───────────

# View logs
aws logs tail /ecs/sleetgale-portal --follow

# Check service status
aws ecs describe-services \
  --cluster $(terraform output -raw portal_cluster_name) \
  --services $(terraform output -raw portal_service_name)

# Check task health
aws ecs list-tasks \
  --cluster $(terraform output -raw portal_cluster_name) \
  --service-name $(terraform output -raw portal_service_name)

╔═══════════════════════════════════════════════════════════════════════════════╗
║                           TROUBLESHOOTING                                     ║
╚═══════════════════════════════════════════════════════════════════════════════╝

Portal Not Accessible (502/503):
─────────────────────────────────

1. Check ECS service is running:
   aws ecs describe-services \
     --cluster $(terraform output -raw portal_cluster_name) \
     --services $(terraform output -raw portal_service_name)

2. Check container image exists:
   aws ecr describe-images \
     --repository-name sleetgale-portal

3. View logs:
   aws logs tail /ecs/sleetgale-portal --follow

4. Verify health checks:
   # Target should be healthy
   aws elbv2 describe-target-health \
     --target-group-arn $(terraform output alb_target_group_arn)

"Launch" Button Fails:
───────────────────────

1. Check IAM permissions:
   # Portal role needs: sagemaker:CreatePresignedDomainUrl
   
2. Verify domain exists:
   aws sagemaker describe-domain \
     --domain-id $(terraform output -raw sagemaker_domain_id)

3. Test URL generation manually:
   aws sagemaker create-presigned-domain-url \
     --domain-id $(terraform output -raw sagemaker_domain_id) \
     --user-profile-name default-user

Container Won't Start:
──────────────────────

1. Check CloudWatch logs for errors
2. Verify ECR image was pushed successfully
3. Check environment variables in task definition
4. Ensure IAM execution role has ECR pull permissions
